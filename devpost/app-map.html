MENU ATELIER · REFERENCE MAP

Follow a price into the PDF.

This studio imports menu content, lets the restaurant edit it, arranges it into pages and exports selectable PDF text. This is a reference route. The learner has not completed a live code tour or reflection.

1. Edit a pricedist/app.js
updateItem, finishEdit and commit

The price input calls parsePrice. A validated edit session updates the paper immediately. Done commits one history action and saves locally. Escape discards that session. Invalid fields block export and navigation.

2. Arrange the menudist/layout.js
layoutMenu

The selected composition measures and wraps text with the exact font bytes used in print. It creates final positions in points and item hit regions. Long menus paginate.

3. Show and exportrenderSVG
dist/export.js
createPDF

The preview and PDF consume the same measured text lines and vector elements. Local licensed fonts are embedded in the PDF. A changed price stays selectable text in both results.

Where the other work lives

Import a restaurant menu

dist/import.js owns parseImport, candidateFromText, extractPDF and recognizeImage. reviewCandidate and renderReview in dist/app.js show the candidate before replacing the active draft. Missing prices remain reviewable. OCR does not infer allergen labels.

Change a design

Start with the compositions registry in dist/print-compositions.js. Each print-studio module owns a page architecture. print-kit measures common text primitives. layoutMenu normalizes immutable scenes. Change studio controls in dist/styles.css. dist/document-fonts.js prepares static font bytes and measures text through fontkit. dist/fonts/ includes the font files, manifest and licenses.

Change validation or history

dist/model.js owns validateMenu, parsePrice and createHistory. Prices use integer minor currency units. Drafts save locally through persist in dist/app.js. JSON export is the portable backup.

Check source examples

research/sources.json records source snapshots. scripts/examples.mjs normalizes them into dist/examples/. scripts/grade.mjs reproduces the twelve PDF designs and editable JSON backups.

A practice to reuse

Write an observable acceptance condition before building. Here, prd.md > Export requires the changed price in the actual PDF. The original demo changes Whipped ricotta from $12.00 to $14.50. The real paper editor updates the printed amount. The matching PDF must retain that exact amount in selectable text. A separate layout review found multiline footer content could exhaust memory. tests/app-layout.test.mjs now checks that failed layout leaves the previous draft and stored bytes intact.

Run and verify

Run npm start in the project and open the printed http://127.0.0.1:4387 address. Run npm test for behavior checks. Run node scripts/grade.mjs to regenerate the grading files. The core editor and PDF export need no API key. PDF fonts cover the supported Latin characters and currency symbols. Unsupported glyphs fail preflight without changing saved work. OCR uses the vendored English model.
